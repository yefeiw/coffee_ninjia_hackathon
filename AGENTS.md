# AGENTS Instructions

## Scope
These instructions apply to the entire repository.

## Documentation Discipline
When making code or behavior changes, update documentation if needed:
- `README.md` (uber doc / entry point)
- relevant files in `docs/` (`product.md`, `tech_design.md`, `ui.md`, `progress_log.md`)

If no docs update is needed, briefly justify why in your final summary.
